Privacy Policy

This policy covers the Brainrot Fight game for Android, Windows and the browser (“the game”), made by an independent developer (Alex K).

In short: the game has no accounts, no ads and no analytics. We do not collect, store or sell any personal data.

What stays on your device

The game saves a few settings on your device only: the chosen language, whether sound is on, which fighters have finished Arcade mode, whether the first-fight tip has been shown and whether the hidden super forms are switched on. They never leave the device, and uninstalling the game (or clearing its data) deletes them.

Online play

The Online mode is optional. When you create or join a room, the two devices connect directly to each other (peer to peer) to exchange button presses and the state of the fight. To find each other they use these third-party services:

  • the public PeerJS signaling server (0.peerjs.com), which passes the 4-digit room code and connection details;
  • a STUN server run by Google (stun.l.google.com) and PeerJS relay servers (*.turn.peerjs.com), used only to set up the connection.

Like any internet connection, these services and the other player’s device can see your IP address while you play online. The game does not send your name, contacts, location or any other personal information, and we do not store anything about the match. If you never use Online mode, the game makes no network connections.

Children

The game does not knowingly collect personal information from anyone, including children.

Permissions

The Android app asks only for internet access, which is used for Online mode, and for vibration, used for a short buzz when a hit lands.
